## Before Every Release

- [ ] Bump version in `src-tauri/Cargo.toml` and `src-tauri/tauri.conf.json`.
- [ ] Run `npm run test:ci`.
- [ ] Verify the Release workflow has all required GitHub secrets.
- [ ] Test the full pipeline: hotkey, speech, AI response, TTS, overlay, capture, input, close-to-tray, and relaunch.

## GitHub Release Steps

1. Tag: `git tag v0.x.x && git push origin v0.x.x`, or manually run the Release workflow with `releaseTag=v0.x.x`.
   - CI checks out the exact tag via `RELEASE_TAG`.
   - CI builds Windows, macOS Apple Silicon, macOS Intel, and Linux with the production `sqlcipher` feature.
   - CI keeps the GitHub release as a draft while platform trust checks and updater manifest verification run.
2. Confirm the release workflow completed all trust checks.
   - Windows: `signtool verify /pa /all /tw /v` passed for shipped installer artifacts.
   - macOS: `codesign --verify --deep --strict`, `spctl --assess --type execute`, and `xcrun stapler validate` passed.
   - Linux: AppImage and non-empty Tauri updater `.AppImage.sig` evidence was uploaded.
3. Confirm `latest.json` was generated by CI and verified with `scripts/verify-release-artifacts.sh`.
   - Every platform entry must have a URL under `dantericardo88/DanteClicky/releases/download/<tag>/`.
   - Every platform signature must exactly match the corresponding downloaded `.sig` file content.
4. Confirm `SHA256SUMS` was attached to the release and covered by the GitHub artifact attestation evidence.
5. Confirm the workflow published the draft release only after `latest.json`, `SHA256SUMS`, trust evidence, and attestations were uploaded and verified.
6. Run the local Dimension 47 gate:

```powershell
npm run check:dim47-release -- -ReleaseTag v0.x.x -FailOnBlocked
```

7. Record strict installed-artifact manual smoke logs.
   - `docs/cross-platform-smoke/YYYY-MM-DD-windows-v0.x.x.md`
   - `docs/cross-platform-smoke/YYYY-MM-DD-macos-v0.x.x.md`
   - `docs/cross-platform-smoke/YYYY-MM-DD-linux-v0.x.x.md`

## Signing And Notarization

- Apply for Windows code signing and set `WINDOWS_CERTIFICATE` plus `WINDOWS_CERTIFICATE_PASSWORD`.
- Keep `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` configured for updater signatures.
- Configure macOS signing/notarization secrets: `APPLE_ID`, `APPLE_PASSWORD`, `APPLE_TEAM_ID`, `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, and `KEYCHAIN_PASSWORD`.
- CI signs platform artifacts automatically once the relevant secrets exist.
